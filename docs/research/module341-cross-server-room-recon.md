# Module 341 跨服房间「创建房间」抓包侦察记录 (2026-11-10)

## 输入
- 用户提供的 Wireshark 抓包（qq s0「同尘」，等级 300、体力 105）。
- 客户端 → 8200 主服，12 字节业务包；服务端 53 字节回包。

## 线格式复核
`[Uint32 BE 长度][Uint32 BE ActionID][载荷]`，长度 = 4 + 载荷长度。

- 客户端请求载荷（去掉以太网/IP/TCP 头后）：
  `00 00 00 08 | 01 55 00 04 | 01 55 00 01`
  - 长度 = 8，ActionID = `0x01550004` → **Module 0x0155 (341), Action 4**
  - 载荷 = `01 55 00 01`（4 字节，疑似 `[Uint16 341][Uint16 1]` 的玩法/类型参数，待二次样本确认）
- 服务端回包：
  `00 00 00 31 | 01 55 00 04 | <45 字节载荷>`
  - 长度 = 0x31 = 49 = 4 + 45，ActionID 与请求一致。
- 对照 Golden：`c2s_m0_a23.bin` = `00000008 00000017 00000030`；心跳的载荷 4 字节。
  因此 12 字节包既可能是心跳（ActionID `0x17`），也可能是带 4 字节参数的业务请求，**必须看 ActionID 区分**。

## 回包载荷解析（45 字节）
```
04 | 00 00 07 d1 | 01 | 00 01 | 01 | 00 03 95 2d | 00 06 "同尘"
   | 00 02 "s0" | 00 06 <账号> | 01 2c | 00 69 | 00 00 00 00 00 00 01 00
```
| 偏移 | 值 | 推断含义 |
| --- | --- | --- |
| 0 | `04` | 结果码 SUCCESS（与登录 M0:A0 的 result=4 一致） |
| 1-4 | `0x000007d1` = 2001 | 房间 ID |
| 5 | `01` | 房间状态/类型 |
| 6-7 | `0x0001` | 成员数量（=1）或座位号 |
| 8 | `01` | 成员状态/座位 |
| 9-12 | `0x0003952d` = 234797 | 玩家 ID（与叶公好龙面板 player_id 一致） |
| 13-14 | `00 06` | 名称长度，随后 UTF-8「同尘」 |
| - | `00 02 "s0"` | 服务器名 |
| - | `00 06 <账号>` | 平台账号 |
| - | `01 2c` | 等级 300 |
| - | `00 69` | 体力 105 |
| 末 8 字节 | `00 x6 01 00` | 待确认（外观/VIP/准备态等） |

结论：这是跨服房间的「创建房间成功」回包，返回房间 ID 与成员快照（角色名/服/账号/等级/体力）。
Module 341 的具体类名尚未确认（候选：跨服房间/队伍类，服务于全服伏魔塔）。
