## 模块定位

- Module 882 = 纪元秘藏 / 轮回图录（客户端类 `Mod_EraLunHuiAlbum_Base`，
  入口 `EraTreasureView` → `EraLunHuiAlbumView`）。
- 动作（与抓包一致）：
  - `882/0 panel_info` 面板；
  - `882/1 get_task_info [Int tab]` 任务列表（tab 1..5）；
  - `882/2 get_task [Int id]` 领取任务奖励；
  - `882/3 get_karma_award [Int id]` 领取轮回奖励；
  - `882/5 get_karma_cycle_award` 轮回周期状态（返回列表）。

## 882/1 回包

`[Short count] + count × [Int id, Int state, Int claimed] + Int tail`

- `claimed=1` 表示已领取；`0` 表示可尝试领取。
- 服务端对条件不满足的任务返回非 0 结果码（实测 3），应跳过并继续后续条目。
- 实测 tab5（轮回图录）9 条任务：`(614,2,0),(611,2,1),(618,10,0),(616,10,0),
  (617,10,0),(613,2,0),(619,10,0),(612,2,0),(615,10,0)`，tail=5。

## 自动化

1. `882/0` 面板（结果码 0 才继续）；
2. 遍历 tab 1..5：`882/1` 取列表，对 `claimed=0` 的条目逐个 `882/2`；
   - 成功计数；非 0（条件不满足）记录后继续；
3. 最后调用 `882/5` 刷新轮回周期状态（只读）。

单轮上限 80 次领取，不消耗元宝。
